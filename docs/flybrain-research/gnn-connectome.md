## Synthesis
- F1 is replicated widely, but most high numbers are transductive/seeded or random splits on connectivity-defined labels (F8). Our grouped, baseline-gated protocol is stricter than anything found.
- F5/F9: no primary source shows a GNN beating gradient-boosted trees on neuron-level connectome tasks under grouped/inductive splits. Only direct comparison (flywire-gnn, random split): MLP ~= GraphSAGE accuracy, SAGE better macro-F1, GCN much worse. General ML literature (Grinsztajn, BGNN, C&S, Shchur) predicts trees competitive, hybrids win, and protocol effects rival architecture effects.
- F7: 2-layer SAGE aggregation ~ handcrafted 2-hop composition, so expect small GNN gain.
- Leakage routes: message passing through test-node edges, label propagation, full-graph node2vec/spectral embeddings, near-duplicate nodes.
- F3: connectome-constrained models take predicted NT as input; sign errors matter (Shiu) and parameters are degenerate given wiring (Beiran).

## Ideas to adopt
1. Add HGB + Correct&Smooth and a BGNN-style hybrid as F9 baselines.
2. Run GraphSAGE fully inductive: mask test-group labels and partner-category features; report random-vs-grouped gap for the GNN as in F5.
3. Add ASE/node2vec features fit per split (train subgraph or out-of-sample ASE) as an F7 comparator.
4. Cross-animal transfer: restrict to edges >10 synapses or >=0.9% input (Schlegel); expect ceiling from ~1/3 non-reidentifiable types.
5. Report macro-F1 per class (GNN gains show on rare classes).
